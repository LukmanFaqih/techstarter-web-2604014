Tentang Teknologi Informasi

Teknologi Informasi adalah jurusan yang mempelajari tentang apa dan bagaimaa cara menggunakan, mengelola, dan membuat teknologi untuk menyimpan dan membagikan data

Tujuan Capaian

Mahasiswa dapat memahami cara kerja teknologi dan mampu membuat inovasi dalam bidang tersebut baik software maupun hardware

Agenda

  1. Mengenal cara kerja halaman web
  2. Menyusun struktur HTML semantic
  3. Mencoba DevTools dan debugging
  4. Menyimpan checkpoint dengan Git

Apa yang Akan Dipelajari?

  • Membaca struktur halaman sebagai developer.
  • Memilih tag berdasarkan makna konten.
  • Mendiagnosis link dan gambar yang gagal.
  • Menyimpan perkembangan project dengan Git.
